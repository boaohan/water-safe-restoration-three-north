## 实际验证结果

9 个分析阶段均已在新的 Windows / Python 3.12 环境执行完成。重跑保留了 4,784 个候选方案、相同的 480 个 Pareto 方案标识、相同的 25 个选定方案标识，以及全部 58 个单元的管理分类。22 个 low-tree mixed 与 3 个 shrub–herbaceous 的结构数量也保持一致。原有图表输入已通过数值核对，Figure 4、Figure 5 均可重新绘制。

但“运行成功”不等于所有数字逐位一致。严格比较发现 R03 及下游存在小幅数值差异：基准 V_hydro 最大差约 0.000256，选定 V_target 最大差约 0.000170；q85 敏感性列最大差约 0.006295。原计算环境未提供，差异原因尚未最终确定。ExistingWoodyContext 还存在布尔值写成 True/False 或 1.0/0.0 的表示差异。完整结果见 reproduction_comparison.json；原始结果未被替换。
