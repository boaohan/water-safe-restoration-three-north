# Research companion v1.0.0

Code and derived-data companion for groundwater-constrained restoration in the Three-North region.

Author: Aohan Bo, Beijing Forestry University, Beijing, China.
ORCID: https://orcid.org/0009-0002-0355-0262.
Code: MIT. Author-owned data, figures and documentation: CC BY 4.0 (see LICENSE for scope).

Includes aggregated 2005–2024 inputs, nine R02–R09 analytical scripts, archived results, revised Figure 4/5 data, canonical rasters and portable plotting code. Represents 58 analytical units, 4,784 candidates, 480 Pareto records and 25 selected compromises.

All nine stages were executed in a new environment. Pareto/selected candidate identities and management classifications match the archived results; small numerical differences from R03 onward remain documented. Figure 4/5 scripts reproduce the archived chart data. See docs/VALIDATION.md for actual execution evidence and docs/SCOPE_AND_PROVENANCE.md for missing upstream preprocessing and local-reference limitations.

This is a prepared release; no GitHub release or Zenodo DOI has yet been published.
